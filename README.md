High-converting, visually stunning instant selling and cashout marketplace for Counter-Strike 2 (CS2) skins. Built with a modern gaming/fintech obsidian palette, interactive 3D physics, real-time live payout telemetry, and an inventory sandbox valuation engine.

---

## ⚡ Features

- **Obsidian & Cyber Mint Aesthetic:** Deep obsidian base (`#070A0E`), translucent glass cards with backdrop blur, cyber emerald (`#10B981`) and electric turquoise (`#06B6D4`) ambient lighting.
- **Sticky Glassmorphic Navbar:** Real-time bot status ticker (`32 Online • 38s avg`), live multi-currency switcher (`USD $`, `EUR €`, `UAH ₴`, `CRYPTO ₮`), and shimmering animated CTA.
- **Hero & 3D Centerpiece:** Interactive Steam Trade URL valuation calculator and 3D parallax mouse-tracking CS2 weapon showcase (Karambit Gamma Doppler Emerald, AWP Dragon Lore) with live telemetry badges.
- **Infinite Dual-Direction Marquee:** Faded edge masks with 16+ payout rails across Cards/Fiat (Visa, Mastercard, Apple Pay, Revolut, SEPA, Monobank) and Crypto (USDT, BTC, ETH, SOL, LTC, TON).
- **Live Real-Time Payouts Stream:** Auto-streaming real-time feed with weapon wear badges, float bars, payout methods, and green payout numbers.
- **Interactive Inventory Sandbox:** Testable CS2 inventory grid with authentic skins, rarity glows, wear tags, StatTrak badges, applied tournament stickers (Titan Holo, iBUYPOWER Holo, Crown Foil), inspect modal, and sticky dynamic payout calculation sidebar.
- **Steam Trade Offer Simulator:** Confetti celebration, 6-digit Anti-API Scam Handshake token (`SKC-9824`), countdown timer, and simulated transaction receipt.
- **Why Choose Us Bento Grid:** 4 cards with cursor-following spotlight glows, speed telemetry, interactive valuation comparison slider ($100-$5,000), and fee calculator.
- **3-Step How It Works Timeline:** Animated progress line connecting trade URL connection, valuation, and settlement.
- **Trustpilot Reviews & Modern FAQ:** 4.9/5 verified social proof and smooth expandable FAQ accordion.

## 🚀 Quick Start

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

### Production Build

```bash
npm run build
```

---

## 🌐 Deploy on Vercel

This repository is optimized for one-click deployment on [Vercel](https://vercel.com/):

1. Import this repository in your Vercel dashboard.
2. Framework preset: **Vite**.
3. Build command: `npm run build`.
4. Output directory: `dist`.
5. Deploy!
